# Olympiad Solutions

Solutions to competitive programming problems in Python.

- `acmp/` — problems from acmp.ru
- `atcoder/` — AtCoder
- `eolymp/` — e-olymp, including Eolymp Cup #2
- `graphs/` — graphs, including traversals, Dijkstra, connected components, etc.
- `algorithms/` — basic algorithms, including sorting, GCD/extended Euclidean algorithm, fast exponentiation, sieve, backtracking, and greedy algorithms
- `contests/` — solutions from olympiads and cups (University Cup 2025, etc.)
- `misc/` — miscellaneous small problems
